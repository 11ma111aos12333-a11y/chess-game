# لعبة الشطرنج — Chess Game v2.1

لعبة شطرنج كاملة القوانين في ملف HTML واحد (`chess.html`)، مع تطبيق أندرويد (APK) يُبنى تلقائياً عبر GitHub Actions.

## المميزات

### أساس اللعبة
- جميع قوانين الشطرنج الرسمية: التبييت، الأخذ بالتجاوز، الترقية، الكش، الكش مات، الجمود، والتعادلات (نقص القطع، التكرار الثلاثي، قاعدة الخمسين نقلة).
- اللعب مع صديق على نفس الجهاز أو ضد الكمبيوتر بثلاثة مستويات: سهل، متوسط، وصعب (محدّث: بحث متدرج حتى عمق 4).
- نظام نقاط يقيس الأداء (أسر، كش، تبييت، ترقية، شوكة، مبادلة رابحة، كش مات) مع رسائل تشجيع للحركات المميزة.
- وضع ليلي/نهاري، أصوات مدمجة، تراجع عن النقلات، قلب اللوحة، ولوحة مستقرة تماماً لا يتغير حجمها أثناء اللعب.

### جديد في الإصدار 2.1 — اللمسات الأخيرة
- **شاشة بداية سينمائية**: رقعة شطرنج تُبنى بموجة من المركز، حلقة ذهبية دوّارة حول الحصان، وعنوان متدرج الذهبي مع شريط تحميل أنيق — تختفي تلقائياً أو باللمس.
- **قائمة رئيسية جديدة**: شعار متحرك، زر «العب الآن» الرئيسي بلمعة تمر، الألغاز والإنجازات في بطاقتين، وزر إعدادات تحته وزر خروج — مع شرائح إحصاءاتك (مبارياتك، انتصاراتك، ألغازك).
- **استئناف المباراة**: اخرج للقائمة في أي لحظة وارجع لتكمل من حيث توقفت — الساعة تتوقف مؤقتاً وتعود معك.
- **نافذة إعدادات كاملة** من القائمة: المظهر نهاري/ليلي، الأصوات، شريط التقييم، نقاط النقلات، الإحداثيات، وألوان اللوح.
- **خروج حقيقي**: زر الخروج يغلق التطبيق فعلياً على أندرويد (بعد تأكيد مهذب)، وفي المتصفح يظهر وداع لطيف.
- **زر رجوع أندرويد ذكي**: يغلق النوافذ أولاً، ثم يعود للقائمة من أي شاشة، والضغط مرتين من القائمة يخرج.
- **تنعيم الواجهة كاملة**: انتقالات ناعمة بين الشاشات، خلفية رقعة خافتة، رأس زجاجي شفاف، ضغط إسفنجي للأزرار، ولمعات على الأزرار الرئيسية.

### جديد في الإصدار الثاني
- **وضع الألغاز**: 179 لغزاً مولّداً ومتحققاً منه آلياً (كش مات في نقلة/نقلتين، شوكة، كسب مادة)، مع لغز يومي يتغير كل يوم، فئات، سلسلة حلول، وتلميحات.
- **مراجعة المباراة**: بعد انتهاء أي مباراة، تصنيف كل نقلة (رائعة/عظيمة/الأفضل/ممتازة/كتابية/غير دقيقة/خطأ/فادحة)، نسبة دقة لكل طرف، منحنى التفوق عبر المباراة، وسهم أفضل نقلة عند الأخطاء.
- **شريط التقييم الحي**: يُظهر من المتفوق لحظياً بعد كل نقلة (قابل للإخفاء من الإعدادات).
- **مؤقت المباراة**: بليتز 3+2 و5+3 وسريع 10 دقائق مع ساعة لكل لاعب وزيادة لكل نقلة، والخسارة بنفاد الوقت.
- **تصفح سجل النقلات**: انقر أي نقلة لاستعراض موضعها، مع أزرار تنقل ولوحة مفاتيح، والعودة الفورية للوضع المباشر.
- **أسماء الافتتاحيات**: تظهر تلقائياً (الدفاع الصقلي، غامبت الوزير، الروبي لوبيز...).
- **زر تلميح** أثناء اللعب يرسم سهم أفضل نقلة.
- **إنجازات وإحصائيات**: 14 إنجازاً مرتبطاً بمهارة حقيقية، وسجل مباريات ونسب فوز وإحصاءات ألغاز، محفوظة محلياً.
- **ثيمات لوح جديدة**: كلاسيكي، زمردي، رمادي ملكي، خشب الجوز + إظهار/إخفاء الإحداثيات ونقاط النقلات.

## تحميل تطبيق أندرويد

من صفحة الإصدارات (Releases):

```
https://github.com/11ma111aos12333-a11y/chess-game/releases
```

حمّل ملف `chess-game-release.apk`، فعّل خيار "التثبيت من مصادر غير معروفة" في إعدادات الهاتف، ثم ثبّت الملف. التطبيق يعمل دون اتصال بالإنترنت ولا يطلب أي أذونات.

متطلبات التشغيل: أندرويد 5.0 أو أحدث، ويُفضّل أن يكون Android System WebView محدّثاً (يتم تحديثه تلقائياً عبر متجر Play).

## اللعب في المتصفح

افتح ملف `chess.html` في أي متصفح حديث، أو جرّب النسخة المنشورة على GitHub Pages:

```
https://11ma111aos12333-a11y.github.io/chess-game/chess.html
```

## البناء التلقائي (GitHub Actions)

كل دفعة (push) إلى الفرع الرئيسي تُشغّل الملف `.github/workflows/android.yml` الذي يقوم بـ:

1. تثبيت JDK 17 و Gradle.
2. بناء نسختي Debug و Release من التطبيق (غلاف WebView حول اللعبة).
3. رفع الـ APK كـ Artifact وإنشاء إصدار (Release) يحتوي ملف `chess-game-release.apk` جاهزاً للتثبيت.

رقم الإصدار يُقرأ من ملف `VERSION` في جذر المستودع.

## هيكل المشروع

```

VERSION                                     رقم الإصدار الحالي

android/app/src/main/assets/chess.html      نسخة اللعبة داخل التطبيق
.github/workflows/android.yml               سير بناء الـ APK
```
